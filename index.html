                  What is published

                  The recent section is generated once per day from a bounded 90-day local index. The all-time section is generated from the private, encrypted-at-rest raw archive in Cloudflare R2; only a small aggregate file is committed. Published fields are counts, country codes, top public source IPs, normalized command names, attempted usernames, and captured-file SHA-256 hashes. Passwords, login messages, complete command lines, URLs, session identifiers, and captured file contents or samples never enter this repository.

                  Counts describe this sensor's observations, not the whole Internet. Automated scanners, relays, VPNs, and compromised hosts can all affect the results. Usernames and source addresses are observed inputs, not proof of identity.

                  Methodology and source Data timestamps are UTC.
