        What is published

        This page is generated once per day from a bounded local index. It contains counts, country codes, top public source IPs, and normalized command names. Raw logs, passwords, complete command lines, URLs, session identifiers, captured files, and malware samples never enter this repository.

        Counts describe this sensor's observations, not the whole Internet. Automated scanners, relays, VPNs, and compromised hosts can all affect the results.

        Methodology and source Data timestamps are UTC.
